# Domain Model

## Philosophy

The Canonical City Model is the single source of truth.

No package except `core` may define its own Building, City or Road classes.

The parser converts FoE Helper exports into this model.

The renderer consumes this model.

The AI consumes this model.

Everything communicates through this model.

# Design Rules

The Domain Model

- never depends on FoE Helper
- never depends on React
- never depends on AI

The model must stay stable even if FoE Helper changes its export format.
