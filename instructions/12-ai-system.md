# AI System

## Vision

The AI is the intelligence of ForgeMind.

ForgeMind itself never performs strategic optimization.

ForgeMind prepares context, validates responses and visualizes results.

Every optimization decision is generated by one or more Large Language Models.

# Knowledge

Knowledge is versioned.

Knowledge can be reordered.

Official

Community

# Conversation Memory

Each project owns its own conversation.

Conversation is persisted.

Conversation is included in future prompts.

Users may clear history.

Users may branch conversations.

---

# Response Format

The AI shall return JSON only.

Markdown explanations are optional.

The JSON schema is authoritative.
