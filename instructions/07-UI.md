# User Interface

## Philosophy

ForgeMind is a desktop application running inside the browser.

The application should feel similar to

- Visual Studio Code
- IntelliJ IDEA
- Figma
- Blender

It is NOT a mobile-first application.

Mouse and keyboard are primary input methods.
